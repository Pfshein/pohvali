# Room Feature Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Подготовить проверяемый frontend-каркас новой главной фичи «Комната» без изменения backend и без преждевременной замены работающего главного экрана.

**Architecture:** Вертикальный срез `features/room` содержит Pixi-независимую модель и тонкий React → lifecycle → Pixi адаптер. React владеет сериализуемым `RoomState` и DOM-командами; Pixi владеет canvas/display objects и сообщает только итог перемещения экземпляра.

**Tech Stack:** React 19.2, TypeScript 6 strict, PixiJS 8.20, Vite 8, Vitest 4.

**Spec:** `docs/superpowers/specs/2026-09-04-room-design.md`

## Global Constraints

- Существующие продуктовые инварианты `docs/product-brief.md` сохраняются.
- Личные тексты похвал не входят в состояние комнаты и не передаются PixiJS.
- PH-901 не добавляет backend endpoint, таблицу или долгоживущий сервис.
- Нормализованные координаты всегда конечны и ограничены диапазоном `0…1`.
- Canvas не заменяет семантические DOM-кнопки продуктовых действий.
- `StarArcHero` и текущий App flow остаются до отдельной UX-приёмки RoomHome.

## File Structure

- `frontend/src/features/room/model/room.ts` — типы, слои, сортировка и перемещение.
- `frontend/src/features/room/model/placement.ts` — зоны и нормализованная геометрия.
- `frontend/src/features/room/model/serialization.ts` — versioned JSON boundary.
- `frontend/src/features/room/catalog/roomCatalog.ts` — manifest, templates и создание экземпляров.
- `frontend/src/features/room/catalog/starterRoom.ts` — стартовое состояние.
- `frontend/src/features/room/runtime/RoomRuntime.ts` — тестируемая lifecycle-машина.
- `frontend/src/features/room/runtime/ViewGeneration.ts` — защита keyed async-load от stale completion.
- `frontend/src/features/room/runtime/RoomDragSession.ts` — pointer ownership, offset и отмена drag.
- `frontend/src/features/room/pixi/PixiRoomRenderer.ts` — Pixi Application, сцена и drag.
- `frontend/src/features/room/components/RoomCanvas.tsx` — React bridge и ResizeObserver.
- `frontend/src/features/room/components/RoomHome.tsx` — изолированный экран-каркас.
- `frontend/src/features/room/*.test.ts` — unit и SSR-контракты.
- `docs/backlog.md` — эпик PH-900 и этапы.
