# Room UI v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить после Telegram-аутентификации обратимо переключаемый Room UI, визуально соответствующий утверждённому мобильному макету, сохранив текущий classic UI и все бизнес-сценарии.

**Architecture:** `App` остаётся владельцем бизнес-состояния и выбирает `classic | room`; room-представление загружается лениво. React владеет HUD, навигацией, sheets и доступностью, существующий Pixi vertical slice — только сценой и pointer lifecycle. Выбор UI хранится в безопасной локальной preference, RoomState и продуктовые данные от неё независимы.

**Tech Stack:** React 19.2, TypeScript 6 strict, PixiJS 8.20, Vite 8, Vitest 4, CSS, Telegram WebApp runtime.

**Spec:** `docs/superpowers/specs/2026-09-04-room-ui-v2-design.md`

## Global Constraints

- Реализация начинается только после явного подтверждения спецификации владельцем продукта.
- Backend, PostgreSQL schema, API, Telegram auth и crypto contracts не меняются.
- Classic UI остаётся стартовым и визуально неизменным до ручного переключения.
- Никакого production query-параметра или route, обходящего `SessionRoot`.
- В интерфейсе нет streak и текста «подряд»; progress использует дни текущего месяца.
- Активный маскот берётся из фактического `MascotCollection`, включая admin assets.
- Текст, кнопки, navigation и sheets остаются DOM; Pixi рисует только комнату.
- PixiJS не входит в initial classic chunk.
- Личные тексты похвал и encryption key никогда не входят в RoomState.
- Каждый implementation task выполняется TDD-циклом RED → GREEN → refactor.
- После каждого task запускаются перечисленные тесты; перед push обязателен `npm run check`.

```ts
export type UiMode = "classic" | "room";
export const UI_MODE_STORAGE_KEY = "pohvala.ui-mode.v1";

export interface StorageLike {
  getItem(key: string): string | null;
  setItem(key: string, value: string): void;
}

export function parseUiModePreference(raw: string | null): UiMode {
  if (!raw) return "classic";
  try {
    const value: unknown = JSON.parse(raw);
    if (typeof value !== "object" || value === null) return "classic";
    const record = value as Record<string, unknown>;
    return record.schemaVersion === 1 && (record.mode === "classic" || record.mode === "room")
      ? record.mode
      : "classic";
  } catch {
    return "classic";
  }
}

export function loadUiMode(storage: StorageLike): UiMode {
  try { return parseUiModePreference(storage.getItem(UI_MODE_STORAGE_KEY)); }
  catch { return "classic"; }
}

export function saveUiMode(mode: UiMode, storage: StorageLike): void {
  try { storage.setItem(UI_MODE_STORAGE_KEY, JSON.stringify({ schemaVersion: 1, mode })); }
  catch { /* preference is best effort */ }
}
```
